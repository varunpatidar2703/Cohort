# NovaCart — SkyMart Inspired UX Clone

This project recreates the overall shopping-dashboard concept of the supplied SkyMart site while intentionally changing the visual identity and user experience.

## Changes
- New brand: NovaCart
- New purple + mint color system
- Cleaner sticky navigation
- Category-first browsing
- Search and price sorting
- Product cards with quick-add
- Slide-out shopping bag
- LocalStorage cart persistence
- Light/dark mode
- Responsive mobile layout
- Toast feedback for user actions

## Run
Open `index.html` directly, or use VS Code Live Server.

The product images are loaded from Unsplash URLs, so an internet connection is needed for those images.
