# GSAP Portfolio — Mini Hackathon Round 2

A responsive developer portfolio built from scratch for the Mini Hackathon Round 2 requirements.

## Included requirements

- About, Skills, Projects, Experience, Education, Achievements and Contact sections
- GSAP animation used meaningfully throughout the portfolio
- GSAP timelines for hero entrance animation
- ScrollTrigger for section reveals, parallax and progress indicator
- Easing and staggered animations
- Responsive layout for desktop and mobile
- GitHub/LinkedIn/contact placeholders ready to customize
- Accessibility support including reduced-motion handling
- No copied template code or UI kit

## Run locally

Because the project uses only HTML/CSS/JS, you can open `index.html` directly. For the best development experience, use VS Code Live Server or any static server.

Example:

```bash
npx serve .
```

## Deploy

### Vercel
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Use the default settings and deploy.

### GitHub Pages
Upload the project to a repository and enable Pages from the repository's Pages settings.

## Customize before submission

1. Replace `Devon Ray` with your name.
2. Replace `hello@example.com` with your email.
3. Add your real GitHub, LinkedIn and Instagram links.
4. Replace project descriptions with your actual work.
5. Update education/experience details to match your real background.
6. Record a short walkthrough video explaining what you learned and one challenge you faced.
7. Deploy the site and add the live URL to your LinkedIn post.
